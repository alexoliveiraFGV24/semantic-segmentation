O repositório tem como objetivo abordar o problema de segmentação de instâncias presente na segmentação semântica em aprendizado profundo.

Os dados utilizados estão disponíveis em: https://bbbc.broadinstitute.org/BBBC038 (usar o stage1_train). Após baixá-lo, crie a pasta `data` no repositório e cole os dados (só colar a pasta stage1_train)

O relatório final está em `\report\report.ipynb`
